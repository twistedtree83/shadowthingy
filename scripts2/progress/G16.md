# G16 — Visual system: import the Claude Design source

Issue: #21 · Branch: `sprint/gnomon-mvp` · Status: **shipped**

## What shipped

The Claude Design source imported via an interactive session's DesignSync
access (the human gate this ticket was parked on), preserved under `design/`,
and applied to `gnomon.html`. The app now wears the board's system:

- **Tokens.** `--paper/--panel/--sunk/--ink/--dim/--faint/--rule/--rule2/
  --accent` plus the map's `--land/--coast`, light palette on `:root`, dark
  palette under `prefers-color-scheme: dark`. `--good/--bad` are kept for the
  debug suite and verdict chips — the board has no equivalent — re-derived to
  sit in both palettes.
- **Type.** Mono uppercase micro-labels at .12–.16em tracking everywhere a
  label names a reading; tabular mono numerals unchanged. The GNOMON wordmark
  at .26em in a 46px header bar.
- **Components.** Segmented ink-on-panel mode selector (Verify/Time/Locate),
  bordered mono toolbar buttons with ink-filled pressed state, hairline
  scrubber (1px track, 2×18px accent thumb), bordered verdict chips instead of
  filled banners, panel inputs, the empty state as a bordered instruction card
  on the sunken stage.
- **Construction language.** Overlay families are distinguished by dash
  pattern, not hue: solid ink verticals, dashed shadows, dotted light rays,
  each over a soft white halo; marks are shape-coded (square base, circle top,
  diamond shadow tip); the accent means exactly one thing on the canvas — the
  object being placed now. Stroke work scales with image size so a 4000px
  photo and an 800px screenshot read the same.
- **Canvases read tokens at draw time** (`themeToken()` / `accentRGB()` in the
  shell): globe sea/land/coast/graticule, band colour, timeline axis/curve/
  windows, loupe. An OS scheme change re-renders via a `matchMedia` listener —
  a redraw, not a reload.
- **Report palette** aligned to the design tokens (ink/dim/faint/rule/accent).

## The gate, verified

`npm run verify` green — 217 tests, purity clean, network clean — plus the app
driven headless in both schemes: three regions render, globe draws with
coastlines and claimed-location ring, scrubber and mode selector styled, debug
panel opens with the in-page suite at 24/24. No Google Fonts, no new hosts.

## Decisions taken

- **IBM Plex is not fetched.** The board specifies it via Google Fonts; the
  network gate forbids fonts outright. System stacks stand in at the board's
  metrics. Recorded in `design/README.md`.
- **No theme toggle.** The board's light/dark toggle is board chrome, and the
  no-storage rule leaves nowhere honest to keep the preference. Both palettes
  ship; `prefers-color-scheme` picks.
- **The board's runtime does not ship.** `support.js`/`image-slot.js` are the
  Claude Design canvas viewer (React scaffolding). They render the board, not
  the app; importing them would have broken the single-file rule for nothing.
- **Colour-coded families became dash-coded.** The old blue/green/amber
  overlay was replaced by the board's one-ink-three-patterns language. This is
  the design's point, not a restyle: on a photograph of arbitrary colour, hue
  is unreliable and the accent must keep its single meaning.

## What was left

- The board's value-with-uncertainty component (domain brackets, tolerance
  span, tier chip with pips) is specified in `design/Gnomon.dc.html` §1i/§1j
  but the readout still renders plain key/value rows. Adopting it properly
  belongs with G17's honesty pass, where band presentation is already on
  trial.
- The scrubber and map caption sit below the fold at short viewports
  (result row is `minmax(360px, 42%)`); pre-existing, unchanged by this
  slice.
