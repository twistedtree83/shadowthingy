# G14 — Guards: low sun, the equinoxes, and a broken residual

Issue: #19 · Branch: `sprint/gnomon-mvp` · Status: **shipped**

## What shipped

`Gnomon.guards` — six guards, a `confident` verdict the result region obeys, and
four assumptions stated with every answer. 16 headless assertions; 203 total.

| id | severity | fires when |
|---|---|---|
| `unbounded` | refuse | the marks do not fix a direction at all |
| `low-sun` | refuse | any part of the band falls below 5° |
| `residual` | warn / refuse | residual exceeds 1.5× / 6× the marking-noise floor |
| `weak-residual-check` | warn | the noise floor is above 5°, so the check has no power |
| `near-equinox` | warn | \|declination\| < 4° |
| `cropped` | warn | the principal point is unknown |

## A refusal changes what is shown

`confident: false` makes the result region **replace** the answer with the
refusal — "answer withheld", followed by the reasons — and dims the sun figures
in the readout. The numbers remain in the debug panel for anyone who needs them,
but they stop looking like a finding.

This was the explicit requirement: a guard that fires must change what the user
sees, not add a caption beside an unchanged confident number.

## The residual guard is relative, and that was forced by measurement

G9 measured that the residual's scale depends entirely on marking precision and
scene geometry — 3px of noise on a small pole produces about **5°** of residual
on a perfectly valid scene. **A fixed threshold would fire on every real
photograph**, and a guard that cries wolf is one people learn to ignore, which
is worse than not having it.

So the guard compares the unperturbed residual against the Monte Carlo's noise
floor for that same scene:

- ≥ 1.5× the floor → warn
- ≥ 6× the floor → refuse
- floor above 5° → **`weak-residual-check`**: tell the user the check cannot
  detect anything here, which is more useful than silently not firing

That last one fires on the demo fixture, correctly: its poles are only ~130px
tall, so marking noise swamps the coplanarity check. **G17 should consider
rebuilding the fixture with larger objects**, both because it is a better demo
and because it would let the residual guard be exercised for real.

Two other calls worth recording:

- **The low-sun refusal triggers on the band, not the median.** A band reaching
  down into the unreliable regime is unreliable even if its midpoint looks
  respectable.
- **The equinox test uses the computed declination, not the calendar date.**
  Equinox dates drift a day or so year to year; the declination does not.

## The blind spot is stated, never detected

From G4: an object perpendicular to a **slope** rather than to gravity — a fence
post on a hillside — gives an elevation measured from the wrong horizon with a
residual of exactly zero. No projective check can catch it.

So it leads the assumptions list, which travels with every answer including
clean ones. There is a test asserting the assumptions name it, so a later slice
cannot quietly drop it.
